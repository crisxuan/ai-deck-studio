# Benchmark Rubric

Score each benchmark deck from 1 to 5 on:

| Metric | Description |
| --- | --- |
| First-glance impact | The deck has a clear dominant visual and does not look like a default template. |
| Page rhythm | Adjacent slides have distinct visual roles and composition patterns. |
| PPT professionalism | The output resembles a real business presentation, not a web page or notes document. |
| Presentability | The narrative has decision value and can be spoken in a meeting. |
| Export stability | HTML, visual verify, PNG, PDF, and PPTX paths remain stable. |
